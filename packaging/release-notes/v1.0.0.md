The first public release: a native TIDAL client for Windows and Linux, written in Rust with no browser inside.

**New**
- **Lossless and Max,** decoded bit-exact.
- **Bit-perfect output** with optional exclusive mode.
- **Fast and light:** opens in under a second.
- **Feels like TIDAL:** Home, Explore, Feed, Collection, lyrics and credits.
- **Music videos** with picture-in-picture.
- **Offline downloads.**
- **TIDAL Upload** for your own music.
- **My Activity** with your top artists.
- **TidaLuna plugins and themes,** off by default.
- **16 languages.**

Which file to download is under [Install](https://github.com/CIoudGuy/tidalfast#install). You need a TIDAL subscription.
