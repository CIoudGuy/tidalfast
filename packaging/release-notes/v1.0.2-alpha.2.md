A dev build with more TidaLuna fixes, a lighter app, and a security pass.

**New**
- **Lighter on your PC.** Plugins no longer keep the app busy while it is covered by other windows, and now playing with plugins uses far less CPU.
- **Removing a plugin removes everything.** Its files, settings and downloaded models (like 3D Cover's) are deleted. Turning a plugin off still keeps them.
- **Themes for one mode say so.** A theme that only shows in Light or Dark mode tells you, instead of looking broken.
- **3D Cover works fully,** including the Base model.

**Fixed**
- **Plugins from Inrixia's store are the same builds TidaLuna uses.** Tidal Tags now writes into the quality pill instead of adding its own box. Plugins you already have move over on their next update.
- **Themes match TIDAL more closely,** including Tidal TUI, Tidal Light and the Cotton Candy family.
- **Now playing no longer leaves parts of itself** over the player bar and the queue when it opens or closes.
- **The player bar's "Playing from" line** is no longer cut off at the bottom.
- **The Plugins page stays in place** when you install or remove a theme or plugin, and each tab remembers where you were.
- **Security fixes.** Damaged songs or covers can no longer crash the app, links only open web addresses, plugins can no longer reach each other's connections or cover a permission prompt, and plugin installs must stay on HTTPS.

Tidalfast is an independent project and is not affiliated with TIDAL.
